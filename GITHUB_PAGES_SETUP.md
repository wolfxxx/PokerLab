# GitHub Pages Setup Guide

This guide will help you enable GitHub Pages for your PokerLab repository so the web interface is accessible at `https://wolfxxx.github.io/PokerLab/`.

## Steps to Enable GitHub Pages

1. **Go to your repository on GitHub:**
   - Navigate to https://github.com/wolfxxx/PokerLab

2. **Open Settings:**
   - Click on the **Settings** tab (top right of the repository page)

3. **Navigate to Pages:**
   - In the left sidebar, scroll down and click on **Pages**

4. **Configure Source:**
   - Under **Source**, select:
     - **Branch:** `main`
     - **Folder:** `/ (root)`
   - Click **Save**

5. **Wait for Deployment:**
   - GitHub will build and deploy your site (usually takes 1-2 minutes)
   - You'll see a message like: "Your site is live at https://wolfxxx.github.io/PokerLab/"

6. **Access Your Site:**
   - Visit: https://wolfxxx.github.io/PokerLab/
   - The web interface should now be live!

## What the Web Interface Does

The `index.html` file provides a web-based version of the PokerLab GUI that:
- ✅ Allows you to visually select bots
- ✅ Configure tournament and PokerTV settings
- ✅ Generates command-line commands you can copy and paste
- ✅ Provides quick start instructions

**Note:** Since GitHub Pages only hosts static files, the web interface cannot actually run tournaments or PokerTV. It generates the commands that you need to run locally on your machine.

## To Actually Run Tournaments

You have two options:

### Option 1: Use the Desktop GUI (Recommended)
```bash
python pokerlab_gui.py
```

### Option 2: Use Command Line
Copy the commands generated by the web interface and run them in your terminal.

## Troubleshooting

- **Site not loading?** Wait a few minutes after enabling Pages - it can take time to deploy
- **404 Error?** Make sure `index.html` is in the root directory (it should be)
- **Changes not showing?** GitHub Pages may cache content - wait a few minutes or clear your browser cache

## Custom Domain (Optional)

If you want to use a custom domain:
1. In the Pages settings, enter your custom domain
2. Configure DNS records as instructed by GitHub
3. Wait for DNS propagation (can take up to 48 hours)
