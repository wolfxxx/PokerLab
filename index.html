Quick Start Instructions

1. Clone the Repository:
git clone https://github.com/wolfxxx/PokerLab.git
cd PokerLab
2. Set Up Python Environment (Optional but Recommended):
python -m venv .venv

# Windows:
.venv\Scripts\activate

# macOS/Linux:
source .venv/bin/activate
3. Run the Desktop GUI (Easiest Method):
python pokerlab_gui.py

The desktop GUI provides the same interface as this web page, but can actually launch tournaments and PokerTV directly!

4. Or Use Command Line:

Use the commands generated above, or see the README for more examples.
